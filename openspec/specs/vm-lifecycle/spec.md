## Purpose

管理虚拟机从创建到销毁的完整生命周期，包括规格调整与穿透式状态查询，是前端云管平台的核心能力。
## Requirements
### Requirement: 创建虚拟机

系统 SHALL 支持基于 cloud 镜像创建虚拟机，创建参数包括名称、CPU 核数、内存大小、磁盘大小、镜像、抽象存储类型、区域、登录密码。创建时系统 SHALL 为该虚拟机分配一个该区域可用的 IP（前端不可选），并将分配结果随创建结果返回。镜像的默认用户名由镜像目录决定，系统 SHALL 在创建时注入用户名、密码与静态 IP 到 cloud-init 配置。虚拟机网络 SHALL 固定使用 vmbr0 网桥。

#### Scenario: 成功创建虚拟机

- **WHEN** 用户提交包含镜像、区域、规格等参数的创建请求
- **THEN** 系统分配 IP、落库元数据并触发 PVE 异步创建，返回虚拟机信息（含分配的 IP 与 creating 状态）

#### Scenario: 区域无可用 IP

- **WHEN** 用户提交创建请求但该区域 IP 池中无空闲 IP
- **THEN** 系统拒绝创建并返回 IP 资源不足的错误

#### Scenario: 区域节点不可达

- **WHEN** 用户提交创建请求但该区域所有节点均不可达
- **THEN** 系统拒绝创建并返回节点不可用的错误

### Requirement: 生命周期操作

系统 SHALL 支持对已有虚拟机执行启动、停止、重启、销毁操作，操作结果以 PVE 实际状态为准。

#### Scenario: 启动虚拟机

- **WHEN** 用户对处于停止状态的虚拟机发起启动请求
- **THEN** 系统调用 PVE 启动该虚拟机，返回操作受理结果

#### Scenario: 销毁虚拟机并释放 IP

- **WHEN** 用户对虚拟机发起销毁请求
- **THEN** 系统销毁该虚拟机并将其占用的 IP 释放回 IP 池

#### Scenario: 对不存在的虚拟机执行操作

- **WHEN** 用户对不存在的虚拟机 ID 发起任何生命周期操作
- **THEN** 系统返回资源不存在的错误

### Requirement: 调整规格

系统 SHALL 支持调整虚拟机的规格。CPU 与内存 SHALL 支持升降配；磁盘 SHALL 仅支持扩容，不得减小。

#### Scenario: 升降配 CPU 与内存

- **WHEN** 用户提交 CPU 或内存的调整请求
- **THEN** 系统按新规格执行调整并返回结果

#### Scenario: 缩小磁盘

- **WHEN** 用户提交小于当前磁盘大小的扩容请求
- **THEN** 系统拒绝该请求并返回磁盘不可缩小的错误

### Requirement: 穿透式状态查询

系统 SHALL 支持查询虚拟机列表与详情，状态数据 SHALL 实时取自 PVE 节点，数据库不维护状态镜像。列表查询 SHALL 合并元数据与实时状态返回。

#### Scenario: 查询虚拟机列表

- **WHEN** 用户请求虚拟机列表
- **THEN** 系统返回包含每个虚拟机元数据与实时状态的列表

#### Scenario: 查询单个虚拟机详情

- **WHEN** 用户请求某个虚拟机详情
- **THEN** 系统返回该虚拟机元数据与实时状态，包含其分配到的 IP

### Requirement: 导入的虚拟机纳入生命周期管理

系统 SHALL 对导入的虚拟机提供与镜像创建虚拟机等同的生命周期能力：支持启动、停止、重启、销毁与规格调整，支持列表与详情透传状态查询。销毁导入的虚拟机时，系统 SHALL 同步销毁其 PVE 侧实体并释放其占用的 IP。

#### Scenario: 导入虚拟机可执行生命周期操作

- **WHEN** 用户对已导入的虚拟机发起启动、停止、重启、规格调整或销毁操作
- **THEN** 系统按与镜像创建虚拟机相同的规则执行操作并返回结果

#### Scenario: 销毁导入虚拟机释放 IP

- **WHEN** 用户销毁已导入的虚拟机
- **THEN** 系统销毁 PVE 侧虚拟机并释放其占用的 IP 回 IP 池
