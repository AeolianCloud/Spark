## Purpose

管理按区域划分的 IP 地址池：IP 池绑定区域并在节点上显式勾选为可用，创建虚拟机时由后端随机分配 IP，实现区域内地址的独占与回收。

## Requirements

### Requirement: IP 池按区域划分

系统 SHALL 支持创建与管理 IP 池，每个 IP 池 SHALL 归属于一个区域，包含网段、网关、DNS 等配置。不同区域的 IP 池不得互相使用。

#### Scenario: 创建 IP 池

- **WHEN** 管理员提交包含区域与网段信息的 IP 池创建请求
- **THEN** 系统创建该区域的 IP 池并生成池内全部 IP 记录

#### Scenario: 跨区域使用 IP 池

- **WHEN** 尝试让某区域的虚拟机使用其他区域的 IP 池
- **THEN** 系统拒绝该使用请求

### Requirement: 节点勾选可用

IP 池 SHALL 在节点上显式勾选为可用状态后才可供该节点使用；未勾选的节点 SHALL 不得使用该 IP 池的地址。

#### Scenario: 勾选节点可用

- **WHEN** 管理员将某 IP 池勾选为某节点可用
- **THEN** 该节点可使用该 IP 池中的地址

#### Scenario: 使用未勾选节点的地址

- **WHEN** 某节点未被勾选但尝试使用某 IP 池的地址
- **THEN** 系统拒绝该分配并返回不可用的错误

### Requirement: 随机分配与独占

创建虚拟机时系统 SHALL 从该区域可用 IP 池的空闲地址中随机选取一个并原子性标记为已占用；同一地址不得同时分配给两个虚拟机。分配出的 IP 不可被前端选择或指定。

#### Scenario: 并发分配同一地址

- **WHEN** 两个创建请求并发且随机范围包含同一空闲地址
- **THEN** 该地址至多被一个请求占用，另一个请求分配到不同地址或返回资源不足

### Requirement: 回收

销毁虚拟机后，系统 SHALL 将其占用的 IP 标记回空闲，可被后续虚拟机再次分配。

#### Scenario: 销毁后回收 IP

- **WHEN** 某虚拟机被销毁
- **THEN** 其占用的 IP 恢复为空闲状态并可被再次分配
