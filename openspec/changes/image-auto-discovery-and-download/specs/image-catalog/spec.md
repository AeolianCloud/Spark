## MODIFIED Requirements

### Requirement: 镜像目录

系统 SHALL 支持维护镜像目录，每个镜像条目 SHALL 包含名称、默认用户名与下载地址（download_url）。镜像在各节点上的存在情况不再由目录记录，而是以 PVE 为权威源实时扫描获取。

#### Scenario: 登记镜像

- **WHEN** 管理员登记一个镜像并填写名称、默认用户名与完整下载地址
- **THEN** 系统将镜像纳入目录并可被创建虚拟机时选择

#### Scenario: 未填写下载地址

- **WHEN** 管理员登记镜像且未提供下载地址
- **THEN** 系统拒绝登记并返回参数错误

### Requirement: 按节点可用性汇总查询

系统 SHALL 支持按区域查询可用镜像，镜像 SHALL 在该区域至少一个启用节点上存在时才被判定为可用，且 SHALL 返回该镜像在区域各启用节点上的存在状态（已下载/未下载）。

#### Scenario: 镜像仅在部分节点存在

- **WHEN** 查询某区域的镜像列表且某镜像仅存在于该区域部分启用节点
- **THEN** 该镜像出现在可用镜像列表中，并展示其在该区域各启用节点上的存在状态

#### Scenario: 镜像在所有节点存在

- **WHEN** 查询某区域的镜像列表且某镜像存在于该区域全部启用节点
- **THEN** 该镜像出现在可用镜像列表中，且各节点状态均为已下载

#### Scenario: 镜像在区域内无节点存在

- **WHEN** 查询某区域的镜像列表且某镜像在该区域没有任何启用节点上存在
- **THEN** 该镜像不出现于可用镜像列表

### Requirement: 镜像感知的节点选择

创建虚拟机时，系统 SHALL 从区域中挑选"可达且该节点上存在所选镜像"的节点承载虚拟机；若区域内没有任何节点同时满足可达性与镜像存在性，系统 SHALL 拒绝创建。

#### Scenario: 部分节点存在镜像

- **WHEN** 在某区域创建虚拟机且所选镜像仅存在于该区域部分启用节点
- **THEN** 系统将虚拟机调度到存在该镜像的节点，且不因镜像缺失而失败

#### Scenario: 区域内无节点存在镜像

- **WHEN** 在某区域创建虚拟机且所选镜像在该区域任何启用节点上都不存在
- **THEN** 系统拒绝创建并返回镜像不可用错误

## ADDED Requirements

### Requirement: 按节点扫描镜像存在状态

系统 SHALL 通过 PVE 存储内容 API 扫描每个节点 `/var/lib/vz/import/` 目录（对应 local 存储的 import 内容），并将扫描到的文件名与镜像下载地址（download_url）尾部的文件名匹配，以判定该镜像在该节点上是否已下载。

#### Scenario: 节点已存在镜像文件

- **WHEN** 查询镜像在某个节点的存在状态且该节点 import 目录中存在与 download_url 尾部文件名相同的文件
- **THEN** 系统报告该镜像在该节点已下载

#### Scenario: 节点不存在镜像文件

- **WHEN** 查询镜像在某个节点的存在状态且该节点 import 目录中不存在匹配文件
- **THEN** 系统报告该镜像在该节点未下载

### Requirement: 按节点下载镜像

系统 SHALL 支持将镜像下载到指定节点，下载目标固定为 local 存储的 import 目录。下载可指定单个节点、多个节点或某区域的全部启用节点；下载是异步操作，其结果 SHALL 持久化记录（成功或失败及失败原因）。

#### Scenario: 下载到单个节点

- **WHEN** 管理员请求将镜像下载到单个节点
- **THEN** 系统在节点上启动下载任务，记录操作并最终在镜像列表展示该节点已下载

#### Scenario: 下载到多个节点

- **WHEN** 管理员请求将镜像下载到多个指定节点
- **THEN** 系统在每个指定节点上分别启动下载任务并各自记录操作结果

#### Scenario: 下载到区域全部节点

- **WHEN** 管理员请求将镜像下载到某区域的全部启用节点
- **THEN** 系统在该区域每个启用节点上分别启动下载任务并各自记录操作结果

#### Scenario: 下载失败

- **WHEN** 下载任务在某个节点上失败
- **THEN** 系统持久化记录该节点的失败结果与原因，其他节点的下载不受影响
