## MODIFIED Requirements

### Requirement: 创建虚拟机

系统 SHALL 支持基于 cloud 镜像创建虚拟机，创建参数包括名称、CPU 核数、内存大小、磁盘大小、镜像、抽象存储类型、区域、登录密码，并可选择指定归属用户（user_id，可空）。创建时系统 SHALL 为该虚拟机分配一个该区域可用的 IP（前端不可选），并将分配结果随创建结果返回。镜像的默认用户名由镜像目录决定，系统 SHALL 在创建时注入用户名、密码与静态 IP 到 cloud-init 配置。虚拟机网络 SHALL 固定使用 vmbr0 网桥。

#### Scenario: 成功创建虚拟机

- **WHEN** 用户提交包含镜像、区域、规格等参数的创建请求
- **THEN** 系统分配 IP、落库元数据（含归属用户，未指定则为无主）并触发 PVE 异步创建，返回虚拟机信息（含分配的 IP 与 creating 状态）

#### Scenario: 区域无可用 IP

- **WHEN** 用户提交创建请求但该区域 IP 池中无空闲 IP
- **THEN** 系统拒绝创建并返回 IP 资源不足的错误

#### Scenario: 区域节点不可达

- **WHEN** 用户提交创建请求但该区域所有节点均不可达
- **THEN** 系统拒绝创建并返回节点不可用的错误

### Requirement: 生命周期操作

系统 SHALL 支持对 PVE 节点上存在的虚拟机执行启动、停止、重启、销毁操作，操作结果以 PVE 实际状态为准。用户令牌执行操作时，SHALL 校验目标虚拟机归属该用户，非本人资源 SHALL 返回无权访问错误；管理员令牌 SHALL 可操作全部虚拟机。

#### Scenario: 启动虚拟机

- **WHEN** 用户对处于停止状态的虚拟机发起启动请求
- **THEN** 系统调用 PVE 启动该虚拟机，返回操作受理结果

#### Scenario: 销毁虚拟机并释放 IP

- **WHEN** 用户对已分配 IP 的虚拟机发起销毁请求
- **THEN** 系统销毁该虚拟机并将其占用的 IP 释放回 IP 池

#### Scenario: 操作他人的虚拟机

- **WHEN** 用户令牌对不属于自己的虚拟机发起任何生命周期操作
- **THEN** 系统返回无权访问错误

#### Scenario: 对不存在的虚拟机执行操作

- **WHEN** 用户对 PVE 上不存在的虚拟机 ID 发起任何生命周期操作
- **THEN** 系统返回资源不存在的错误

### Requirement: 穿透式状态查询

系统 SHALL 支持查询虚拟机列表与详情，状态数据 SHALL 实时取自 PVE 节点，数据库不维护状态镜像。列表查询 SHALL 按身份分流：管理员令牌返回该区域全部启用节点上的全部虚拟机（含外部虚拟机）并标识来源；用户令牌 SHALL 仅返回归属该用户的虚拟机，外部虚拟机对用户不可见。

#### Scenario: 查询虚拟机列表

- **WHEN** 管理员令牌请求虚拟机列表
- **THEN** 系统返回列表，包含 PVE 节点上存在但本地无记录的虚拟机，每个虚拟机均带来源标识
- **WHEN** 用户令牌请求虚拟机列表
- **THEN** 系统仅返回归属该用户的虚拟机（含创建与认领），不含外部虚拟机与他人资源

#### Scenario: 查询单个虚拟机详情

- **WHEN** 用户请求某个本地有记录的虚拟机详情
- **THEN** 系统返回该虚拟机元数据与实时状态，包含其分配到的 IP；用户令牌访问他人虚拟机详情 SHALL 返回无权访问错误
