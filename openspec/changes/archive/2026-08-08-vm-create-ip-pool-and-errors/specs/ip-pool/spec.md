## MODIFIED Requirements

### Requirement: 随机分配与独占

创建虚拟机时系统 SHALL 从该区域可用 IP 池的空闲地址中随机选取一个并原子性标记为已占用；同一地址不得同时分配给两个虚拟机。IP 地址本身不可被前端选择或指定，但创建请求 SHALL 可选择指定 IP 池（pool_id，可空）：不指定时系统按区域 IP 池顺序自动选择首个可用池，指定时系统仅在该池内分配且该池必须属于同一区域（否则拒绝）。若区域没有 IP 池、或全部池的白名单节点与启用节点交集为空，系统 SHALL 返回无可用 IP 池的错误，而非节点不可用错误。

#### Scenario: 并发分配同一地址

- **WHEN** 两个创建请求并发且随机范围包含同一空闲地址
- **THEN** 该地址至多被一个请求占用，另一个请求分配到不同地址或返回资源不足

#### Scenario: 指定池内分配

- **WHEN** 创建请求指定了属于该区域的 IP 池
- **THEN** 系统仅在该池的空闲地址中随机分配

#### Scenario: 区域无可用 IP 池

- **WHEN** 创建请求不指定 IP 池，且该区域没有任何 IP 池或全部池无可用候选节点
- **THEN** 系统返回无可用 IP 池的错误（no_available_ip_pool），该错误优先于镜像不可用错误（池配置是创建前置条件），不伪装为节点不可用
