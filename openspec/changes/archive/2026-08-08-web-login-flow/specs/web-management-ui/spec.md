## MODIFIED Requirements

### Requirement: 登录后访问

管理界面 SHALL 要求管理员登录后方可访问与操作；该行为取代早期"无鉴权访问"的已知权衡。未登录访问业务页面 MUST 被导向登录页，全部业务接口请求 MUST 携带有效 JWT 令牌；令牌缺失、无效或过期 MUST 清除本地令牌并跳转登录页。

#### Scenario: 未登录访问业务页

- **WHEN** 未登录用户在浏览器中打开管理界面业务页面
- **THEN** 系统导向登录页，不展示任何业务数据

#### Scenario: 已登录访问与操作

- **WHEN** 已登录管理员打开管理界面并执行任意资源操作
- **THEN** 操作请求携带有效 JWT 令牌并正常完成

#### Scenario: 令牌失效

- **WHEN** 已登录管理员的令牌过期或被后端拒绝
- **THEN** 界面清除本地令牌并跳转登录页
