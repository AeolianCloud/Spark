## ADDED Requirements

### Requirement: 导入虚拟机入口

系统 SHALL 在虚拟机列表页提供"导入虚拟机"操作入口。导入表单 MUST 依次支持选择可用区、该可用区下的节点与节点上未托管的候选虚拟机，提交后调用后端导入接口；导入成功后新虚拟机出现在列表中。候选虚拟机加载失败或导入失败时，界面 MUST 展示后端返回的错误信息。

#### Scenario: 导入已有虚拟机

- **WHEN** 运维人员在虚拟机列表页打开导入入口，选择可用区、节点与候选虚拟机并提交
- **THEN** 系统调用导入接口，成功后该虚拟机出现在虚拟机列表中

#### Scenario: 导入失败展示错误

- **WHEN** 候选列表加载失败（节点不可达等）或导入请求被后端拒绝
- **THEN** 界面展示后端返回的错误信息，不产生任何本地数据变更
