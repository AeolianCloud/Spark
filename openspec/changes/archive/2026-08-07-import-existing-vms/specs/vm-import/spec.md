## Purpose

将 PVE 节点上已有的虚拟机（非 Spark 创建）纳管为 Spark 托管的虚拟机，支持未托管候选查询与导入后的完整管理能力。

## ADDED Requirements

### Requirement: 导入虚拟机

系统 SHALL 支持将 PVE 节点上已有的虚拟机导入为托管的虚拟机。导入请求 MUST 携带区域、节点与 PVE 侧 VMID；系统 MUST 校验区域与节点存在、节点属于该区域且启用、PVE 侧存在该 VMID 的虚拟机。导入成功后，该虚拟机纳入本地管理，出现在虚拟机列表与详情中。

#### Scenario: 成功导入已有虚拟机

- **WHEN** 用户提交包含区域、节点与 PVE VMID 的导入请求，且该虚拟机尚未被托管
- **THEN** 系统读取 PVE 侧虚拟机配置（名称、规格、磁盘大小），建立本地管理记录并返回虚拟机信息（含实时状态）

#### Scenario: 导入已托管的虚拟机

- **WHEN** 用户尝试导入的 PVE VMID 在该节点上已被托管
- **THEN** 系统拒绝导入并返回冲突错误

#### Scenario: 导入不存在的虚拟机

- **WHEN** 用户提交的 PVE VMID 在节点上不存在
- **THEN** 系统拒绝导入并返回资源不存在的错误

#### Scenario: 导入时节点不可达

- **WHEN** 导入请求对应的节点不可达或查询失败
- **THEN** 系统拒绝导入并返回节点不可用的错误，不建立任何本地记录

### Requirement: 导入虚拟机的 IP 策略

系统 SHALL 在导入虚拟机时优先复用 PVE 配置（ipconfig0）中的静态 IP：静态 IP 属于该区域某个 IP 池且地址空闲、池白名单包含该节点时，直接占用该地址；虚拟机无静态 IP（DHCP）或不存在匹配池时，回退为该虚拟机从区域 IP 池分配新地址。池中无可用地址时导入失败并返回 IP 资源不足的错误。

#### Scenario: 复用现有静态 IP

- **WHEN** 被导入虚拟机的 ipconfig0 配置了静态 IP，且该 IP 属于区域内某池、地址空闲、池白名单包含该节点
- **THEN** 系统占用该静态 IP 并记录到虚拟机元数据

#### Scenario: 静态 IP 无匹配池

- **WHEN** 被导入虚拟机的静态 IP 不属于任何可用池，或其池白名单不含该节点
- **THEN** 系统从区域 IP 池中分配新地址记录到虚拟机元数据

#### Scenario: 无静态 IP 且池耗尽

- **WHEN** 被导入虚拟机未配置静态 IP（DHCP）且区域池无空闲地址
- **THEN** 系统拒绝导入并返回 IP 资源不足的错误

### Requirement: 未托管虚拟机候选查询

系统 SHALL 支持按节点查询该节点 PVE 上尚未被托管的虚拟机列表，返回候选虚拟机的 VMID、名称、状态与规格，供导入入口选择。已被托管的 PVE 虚拟机 MUST NOT 出现在候选列表中。

#### Scenario: 查询未托管候选

- **WHEN** 用户按节点查询未托管虚拟机列表
- **THEN** 系统返回该节点 PVE 上全部未被托管的虚拟机（含名称与规格）

#### Scenario: 候选查询节点不可达

- **WHEN** 候选查询对应的节点不可达或查询失败
- **THEN** 系统返回节点不可用的错误

### Requirement: 导入虚拟机的关联字段可空

导入的虚拟机 MUST 不关联镜像与存储类型，MUST 不携带 cloud-init 密码；虚拟机响应中的镜像、存储类型关联字段 SHALL 允许为空，以区分导入虚拟机与镜像创建的虚拟机。

#### Scenario: 导入虚拟机关联为空

- **WHEN** 用户查询已导入虚拟机的详情
- **THEN** 响应中镜像与存储类型关联为空，且不包含任何密码相关字段
