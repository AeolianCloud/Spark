## MODIFIED Requirements

### Requirement: 创建虚拟机

系统 SHALL 支持基于 cloud 镜像创建虚拟机，创建参数包括名称、CPU 核数、内存大小、磁盘大小、镜像、抽象存储类型、区域、登录密码，并可选择指定归属用户（user_id，可空）。创建时系统 SHALL 为该虚拟机分配一个该区域可用的 IP（IP 地址本身不可由前端选择或指定），并将分配结果随创建结果返回。请求可选择性指定 IP 池（pool_id，可空）：不指定时系统 SHALL 按区域 IP 池顺序自动选择首个可用池；指定时系统 SHALL 仅在该池内调度，且该池必须属于同一区域。镜像的默认用户名由镜像目录决定，系统 SHALL 在创建时注入用户名、密码与静态 IP 到 cloud-init 配置。虚拟机网络 SHALL 固定使用 vmbr0 网桥。提交的存储类型 SHALL 处于启用状态且支持磁盘映像（images）内容类型，否则拒绝创建。节点调度 SHALL 只在挂载了所选存储的节点（节点挂载快照非空时）中选择；所选存储未挂载任何候选节点时拒绝创建。

#### Scenario: 成功创建虚拟机

- **WHEN** 用户提交包含镜像、区域、规格等参数的创建请求
- **THEN** 系统分配 IP、落库元数据（含归属用户，未指定则为无主）并触发 PVE 异步创建，返回虚拟机信息（含分配的 IP 与 creating 状态）

#### Scenario: 指定 IP 池创建虚拟机

- **WHEN** 用户提交创建请求并指定属于该区域的 IP 池
- **THEN** 系统仅在该池内调度节点并分配 IP，返回虚拟机信息

#### Scenario: 指定不属于该区域的 IP 池

- **WHEN** 用户提交创建请求并指定不属于所选区域的 IP 池
- **THEN** 系统拒绝创建并返回资源不存在的错误

#### Scenario: 区域无可用 IP

- **WHEN** 用户提交创建请求但该区域 IP 池中无空闲 IP
- **THEN** 系统拒绝创建并返回 IP 资源不足的错误

#### Scenario: 区域无可用 IP 池

- **WHEN** 用户提交创建请求但该区域没有任何 IP 池，或全部 IP 池的白名单节点与启用节点交集为空（无论该区域节点上是否存在该镜像）
- **THEN** 系统拒绝创建并返回无可用 IP 池的错误（no_available_ip_pool），错误消息指明区域并区分"无池"与"池无候选节点"

#### Scenario: 区域节点不可达

- **WHEN** 用户提交创建请求，区域存在至少一个带镜像的候选节点（存在可用 IP 池候选）但这些节点全部不可达
- **THEN** 系统拒绝创建并返回节点不可用的错误（node_unavailable）

#### Scenario: 有池候选但镜像不可用

- **WHEN** 用户提交创建请求，区域存在可用 IP 池候选但没有任何启用节点存在该镜像（且无扫描失败）
- **THEN** 系统拒绝创建并返回镜像不可用的错误（image_not_available_in_zone）

#### Scenario: 提交已禁用的存储类型

- **WHEN** 用户提交创建请求且所选存储类型已被管理员禁用
- **THEN** 系统拒绝创建并返回存储类型不可用的错误

#### Scenario: 提交不支持磁盘映像的存储类型

- **WHEN** 用户提交创建请求且所选存储类型不支持 images 内容类型
- **THEN** 系统拒绝创建并返回存储类型不可用的错误

#### Scenario: 所选存储未挂载任何候选节点

- **WHEN** 用户提交创建请求，所选存储的节点挂载快照非空且不与任何池候选节点重合（或无挂载快照的候选节点）
- **THEN** 系统拒绝创建并返回存储不可用的错误（storage_not_available_in_zone），不产生部分创建

#### Scenario: 按存储挂载过滤调度

- **WHEN** 用户提交创建请求且所选存储的节点挂载快照非空
- **THEN** 系统仅在挂载了该存储的候选节点中调度创建，磁盘落到已挂载该存储的节点上

#### Scenario: 存储不限制节点时调度

- **WHEN** 用户提交创建请求且所选存储的节点挂载快照为空
- **THEN** 系统在所有候选节点中调度创建，不因存储挂载条件排除任何节点
