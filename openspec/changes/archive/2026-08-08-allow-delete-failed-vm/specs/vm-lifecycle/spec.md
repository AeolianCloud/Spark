## MODIFIED Requirements

### Requirement: 生命周期操作

系统 SHALL 支持对 PVE 节点上存在的虚拟机执行启动、停止、重启、销毁操作，操作对象 SHALL 包括本地有记录的虚拟机与本地无记录的未认领虚拟机，操作结果以 PVE 实际状态为准。用户令牌执行操作时，SHALL 校验目标虚拟机归属该用户，非本人资源 SHALL 返回无权访问错误；管理员令牌 SHALL 可操作全部虚拟机。供给失败（status=failed）的虚拟机 SHALL 支持销毁：若其从未创建 PVE 实体（pve_vmid 为空或 0），系统 SHALL 幂等清理本地记录并释放其占用的 IP；若存在 PVE 侧残留实体，系统 SHALL 以 purge 方式销毁残留实体后再清理本地记录并释放 IP。

#### Scenario: 启动虚拟机

- **WHEN** 用户对处于停止状态的虚拟机发起启动请求
- **THEN** 系统调用 PVE 启动该虚拟机，返回操作受理结果

#### Scenario: 销毁虚拟机并释放 IP

- **WHEN** 用户对已分配 IP 的虚拟机发起销毁请求
- **THEN** 系统销毁该虚拟机并将其占用的 IP 释放回 IP 池

#### Scenario: 销毁供给失败的虚拟机

- **WHEN** 用户对供给失败（status=failed）的虚拟机发起销毁请求，且该虚拟机从未创建 PVE 实体（pve_vmid 为空或 0）
- **THEN** 系统跳过 PVE 调用，清理本地记录并释放其占用的 IP，销毁成功

- **WHEN** 用户对供给失败（status=failed）的虚拟机发起销毁请求，且 PVE 侧存在残留实体（pve_vmid 非空且 PVE VM 存在）
- **THEN** 系统以 purge 方式销毁 PVE 残留实体，随后清理本地记录并释放其占用的 IP；若 PVE 实体已不存在（如已被外部移除），仍清理本地记录并释放 IP

#### Scenario: 操作他人的虚拟机

- **WHEN** 用户令牌对不属于自己的虚拟机发起任何生命周期操作
- **THEN** 系统返回无权访问错误

#### Scenario: 控制未认领的外部虚拟机

- **WHEN** 用户对 PVE 上存在但本地无记录的虚拟机发起启动、停止、重启或销毁操作
- **THEN** 系统直接调用 PVE 原生 API 执行操作并返回结果，无需先建立本地记录

#### Scenario: 对不存在的虚拟机执行操作

- **WHEN** 用户对 PVE 上不存在的虚拟机 ID 发起任何生命周期操作
- **THEN** 系统返回资源不存在的错误
